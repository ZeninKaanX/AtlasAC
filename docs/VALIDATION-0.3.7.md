# AtlasAC 0.3.7 validation

Application source: `718de98`; Windows test reader fix: `e70c931` (test-only).
CI: [Windows and Ubuntu](https://github.com/ZeninKaanX/AtlasAC/actions/runs/41004420970).

- Linux: 84 tests discovered, 83 passed and one Windows-only DACL integration test skipped. Native Qt start/results, permission rejection and owned-data deletion exercised with real worker processes.
- Windows CI: the same 84 tests passed, including native `GetNamedSecurityInfoW` / `GetSecurityDescriptorControl` / `GetAce` verification. Directory and export file have protected DACLs with exactly two allow ACEs: current token SID and SYSTEM; no inherited ACEs; both grants have full file control. POSIX-specific assertions run on Linux.
- Initial Windows verification using PowerShell returned null ACL properties and correctly failed CI. It was replaced with direct native reads; the assertions were retained and strengthened. No failing result was accepted as success.
- Synthetic secrets (not real credentials) covered assignments, command flags, JSON text, Bearer/Basic, Cookie, URL userinfo/query and UTF-16 EncodedCommand, including split argv. These finite cases do not establish universal secret recognition.
- Existing report migration masks data, drops general history, preserves age and expires files after seven days. SQLite migration clears legacy undated cache, prunes old records and protects WAL/SHM files. Export symlinks are rejected. Deletion retains unrelated source files. Source browser fixture retains only a relevant download and strips URL query; source database survives.
- Local Linux: [66 static sample checks](linux-ghost-real-037.json), 20 positive files and four benign distributions plus embedded native controls, cold/cached/live comparisons. Windows and Ubuntu CI: 60 checks each over the re-downloadable cohort, 18 positive files / four benign distributions. [Windows](windows-ghost-real-037.json), [Ubuntu](ubuntu-ghost-real-037.json). Previously pinned DoomsDay outer bytes are excluded only from automated re-download; local full cohort includes them.
- Native frozen Linux binary: current module/assets verified with `tools/verify_bundle.py`; folder CLI over the full local cohort produced 20 matches, two expected metadata issues, partial status and exit code 2. Exact-file, exact-member and class-layout evidence was labelled static; no usage claim was set. Samples were not executed.
- Actual previously observed Linux storage permissions were repaired to `.atlasac=700`, reports directory `700`, index `600`; retained existing reports were minimised. No SQLite schema modification was forced into an already-running older app.

The two malformed Hydrogen metadata records remain visible issues; detections are retained and the scan remains partial. Same-source rows are not scored as independent evidence. This validation does not cover arbitrary ghost clients, live injection, every secret format, a real breach exercise, or the organisation's legal processing basis. User-provided controller/contact information is configured but not independently verified. See [PRIVACY.md](PRIVACY.md) and [METHOD-COVERAGE.md](METHOD-COVERAGE.md).
